# CSI606-2026-01 - Remoto - Proposta de Trabalho Final
## Discente: Gustavo Guimarães de Oliveira Dias - 22.2.8020

1. **Resumo**

O site consiste em um fórum sobre peixes criados como pet, abordando informações como seu habitat natural, tamanho que pode chegar, parâmetros básicos\
da água para criar tal animal, sua compatibilidade em questão de tamanho, parâmetros e comportamento com outras espécies e recomendações de rações e\
variedades na alimentação da determinada espécie.

2. **Tema**

O trabalho consiste na elaboração de um site com o tema de peixes pet. Será elaborado um catálogo de peixes contendo suas informações básicas, funcionalidades\
como comparação entre um peixe e outro a respeito das suas compatibilidades, fotografia dos peixes para servir de exemplo e ilustrar o mesmo, rações indicadas\
para a espécie a qual o usuário escolheu e sistema de contas para controle de acesso dos usuários.

3. **Escopo**

Esse projeto terá as seguintes funcionalidades:

   1. Uma listagem dos peixes cadastrados no banco de dados e suas informações
   2. Uma aba comparativa entre dois peixes a sua escolha, mostrando as suas respectivas compatibilidades
   3. Sistema de pesquisa por filtro, para pesquisar determinadas espécies que estão nos parâmetros desejados
   4. Uma aba para peixes marinhos e peixes de água doce
